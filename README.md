## 🏟️ArenaTech
**ArenaTech** é um sistema para gerenciamento de quadras esportivas, permitindo que usuários reservem espaços de forma fácil e rápida.

## Funcionalidades
✅ Reservar quadras para eventos esportivos  
✅ Gerenciamento de horários e disponibilidade  
✅ Controle de usuários e permissões  
✅ Relatórios de uso das quadras  

## 🛠️ Tecnologias Utilizadas
- **Backend:** Django + PostgreSQL
- **Frontend:** JavaScript + HTML/CSS
